<a id="naming"></a>
# Nomenclatura

<a id="selected-term"></a>
## Termo escolhido

O objeto portátil de harness é chamado de **unidade de harness**.

Uma unidade de harness é um espaço de trabalho autônomo do Harneloop com arquivos de controle, instruções para agentes, candidatos, versões, contratos de ambiente, registros de execução e exportações.

<a id="why-this-name"></a>
## Por que esse nome

`Harness unit` é mais claro que `unit`, pois mantém a finalidade visível onde o termo aparece. Também é neutro em relação ao framework em fluxos visuais, de código, pesquisa, automação e agentes de aplicações.

<a id="usage"></a>
## Uso

Use **unidade de harness** em textos para usuários, documentação, menus, prompts e instruções para agentes.

Por enquanto, mantenha nomes de comandos como `harneloop init-unit` e `harneloop units` para evitar mudanças desnecessárias. Esses comandos gerenciam unidades de harness.

Evite usar `unit` isoladamente em textos para usuários, a menos que a frase já deixe o significado claro.
