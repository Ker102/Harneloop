<a id="security"></a>
# 安全

Harneloop 是本地优先的框架，用于构建由代理创建的 harness 单元。代理可能创建工具、执行命令并打包可复用单元，因此安全边界十分重要。

<a id="current-status"></a>
## 当前状态

这是早期公开 alpha 版本。不要把 Harneloop 或 harness 单元视为经过加固的沙箱或安全边界。

<a id="rules"></a>
## 规则

- 永远不要在 harness 单元中存储秘密信息。
- 默认不要打包 `.env` 文件、私钥、凭证、缓存或原始运行轨迹。
- 在检查之前，将生成的候选工具视为不可信。
- 使用框架命令执行提升、回滚和打包。
- 破坏性操作必须先获得用户明确批准。

<a id="reporting"></a>
## 报告

不要在公开 issue 中披露疑似漏洞。如果仓库提供 GitHub 私密漏洞报告表单，请使用该表单。否则，请通过所链接的 GitHub 个人资料私下联系仓库所有者，并提供复现步骤、受影响版本和潜在影响。
