# セキュリティ

Harneloop は、エージェントが構築するハーネスユニットのためのローカル優先フレームワークです。エージェントはツールの作成、コマンド実行、再利用可能なユニットのパッケージ化を行えるため、セキュリティ境界が重要です。

<a id="current-status"></a>
## 現在の状況

これは初期の公開アルファです。Harneloop やハーネスユニットを、堅牢化されたサンドボックスやセキュリティ境界として扱わないでください。

<a id="rules"></a>
## ルール

- ハーネスユニット内に秘密情報を保存しないでください。
- デフォルトでは `.env` ファイル、秘密鍵、認証情報、キャッシュ、生の実行トレースをパッケージに含めないでください。
- 生成された候補ツールは、確認するまで信頼しないでください。
- 昇格、ロールバック、パッケージ化にはフレームワークのコマンドを使ってください。
- 破壊的な操作にはユーザーの明示的な承認を必要としてください。

<a id="reporting"></a>
## 報告

疑わしい脆弱性を公開 issue で開示しないでください。このリポジトリで利用可能な場合は GitHub の非公開脆弱性報告フォームを使ってください。利用できない場合は、リンクされた GitHub プロフィールを通じて所有者に非公開で連絡し、再現手順、影響を受けるバージョン、想定される影響を伝えてください。
