<a id="naming"></a>
# 命名

<a id="selected-term"></a>
## 採用した用語

移植可能なハーネスのオブジェクトを **ハーネスユニット** と呼びます。

ハーネスユニットは、制御ファイル、エージェント向け指示、候補、バージョン、環境契約、実行記録、エクスポートを備えた自己完結した Harneloop ワークスペースです。

<a id="why-this-name"></a>
## この名前を使う理由

`Harness unit` は、どこで使われても目的が明確なため `unit` より分かりやすい名称です。視覚、コード、研究、自動化、アプリケーションエージェントのワークフローにおいても、特定のフレームワークに依存しません。

<a id="usage"></a>
## 使用方法

ユーザー向けテキスト、文書、メニュー、プロンプト、エージェント指示では **ハーネスユニット** を使ってください。

不要な変更を避けるため、当面は `harneloop init-unit` や `harneloop units` などの既存のコマンド名を使ってください。これらはハーネスユニットを管理します。

周囲の表現から意味が明確な場合を除き、ユーザー向けの文章で `unit` 単独の使用は避けてください。
