<a id="naming"></a>
# Nomenclatura

<a id="selected-term"></a>
## Término elegido

El objeto portátil de harness se llama **unidad de harness**.

Una unidad de harness es un espacio de trabajo autónomo de Harneloop con archivos de control, instrucciones para agentes, candidatos, versiones, contratos de entorno, registros de ejecución y exportaciones.

<a id="why-this-name"></a>
## Por qué este nombre

`Harness unit` es más claro que `unit` porque mantiene visible su propósito en cualquier contexto. También es neutral respecto al framework en flujos visuales, de código, investigación, automatización y agentes de aplicaciones.

<a id="usage"></a>
## Uso

Usa **unidad de harness** en textos para usuarios, documentación, menús, prompts e instrucciones para agentes.

Mantén por ahora nombres de comandos como `harneloop init-unit` y `harneloop units` para evitar cambios innecesarios. Esos comandos gestionan unidades de harness.

Evita `unit` por sí solo en textos para usuarios, salvo que la frase ya deje claro el significado.
